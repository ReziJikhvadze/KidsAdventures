# Beki Hero Character Anchor v1

You are generating the **canonical stylized hero anchor image** for a Beki personalized storybook.

## Goal

Create one approved hero character sheet that will serve as the canonical stylized reference for all book illustrations.

## References

- Reference Image A: child real photo — identity only
- Visual Bible: approved hero story outfit and render style

## Hard rules

- The child must remain clearly recognizable.
- Preserve facial identity, apparent age, hair, skin tone, and distinctive features from the photo.
- Use the approved story outfit from the Visual Bible.
- Do not copy the real photo clothing/background/pose unless the Visual Bible explicitly says so.
- The result must be a premium stylized 3D animation character, not photorealistic, not a filtered photo.
- Neutral clean background.
- No extra props unless the Visual Bible explicitly includes one recurring carry item.
- No other characters.
- No text.

## Composition

Show the child in a clean character-sheet-style presentation that includes:
- full body clear view
- front-facing or slight 3/4 view
- readable facial features
- relaxed friendly neutral expression
- consistent proportions

## Output goal

This image is not a story page. It is the approved master anchor used to keep all later pages consistent.

## Delegated image prompt template

Use the official child photo as identity reference. Create a premium stylized 3D animated storybook character sheet of the same child. Preserve the child’s face shape, eye shape, eye color, nose, mouth, jawline, skin tone, hair color, and apparent age. Use the approved story outfit exactly. Show a full-body clear clean front/3/4 view on a neutral simple background. Friendly neutral expression. No photorealism, no photo texture, no filter look. No other characters, no text, no props unless specified in the Visual Bible.
